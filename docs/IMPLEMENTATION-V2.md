# v0.2 implementation contract (DESIGN.md P1/P2)

Shared ownership: DB agent owns server/db.js, server/members.js, server/cli.js, tests/members.test.js, tests/migration.test.js only. Frontend agent owns client/**, index.html, vite.config.js only. Main owns app/auth/services/config/index, integrations, other tests, docs, package files. Do not commit or start servers without coordinating.

## Database target
Keep existing legacy tables/columns so migration is additive and data retained. schema_migrations versioned. members(id UUID PK,github_user_id TEXT UNIQUE NOT NULL,github_login TEXT NOT NULL,display_name TEXT NOT NULL DEFAULT '',module TEXT NOT NULL DEFAULT '',notes TEXT NOT NULL DEFAULT '',role admin|member,status pending_activation|active|disabled,created_by TEXT,first_login_at TEXT,last_login_at TEXT,version INTEGER DEFAULT1,created_at TEXT,updated_at TEXT). github_login is a display snapshot, NOT auth key and NOT UNIQUE (rename/reuse safe).
users retains id=GitHub fixed id,login,name,avatar_url,notifications_enabled,quiet_start,quiet_end and legacy feishu_open_id; add member_id TEXT UNIQUE FK members. sessions add member_id TEXT FK members (legacy user_id still populated); oauth_states add member_id TEXT. Existing users.login UNIQUE collision can be resolved by main auth archiving stale profiles' login before inserting renamed identity, never authorization by login.
feishu_bindings(member_id PK FK members,app_id TEXT,open_id TEXT,status active|needs_confirmation,binding_version INTEGER DEFAULT1,bound_at TEXT,verified_at TEXT,UNIQUE(app_id,open_id)). OAuth creates needs_confirmation; successful self test sets active/verified_at. Demo never real binds or sends.
items add owner_member_id TEXT FK members,version INTEGER DEFAULT1,needs_review INTEGER DEFAULT0,legacy_owner_unresolved INTEGER DEFAULT0,repository_id TEXT. Keep legacy owner for migration only, never auth. notifications add recipient_member_id TEXT FK members,binding_version INTEGER,next_at INTEGER DEFAULT0,error_code TEXT. webhook_inbox add processed_at TEXT. audit_logs(id TEXT PK,actor_member_id TEXT,action TEXT,target_type TEXT,target_id TEXT,before_json TEXT,after_json TEXT,request_id TEXT,created_at TEXT). No secrets/openIds in audit JSON.
